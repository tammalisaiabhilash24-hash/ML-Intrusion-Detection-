How It Works

A beginner-friendly explanation of the local intrusion and email detection workflow.

1. User enters data

The user provides network traffic metrics or email information using the forms on the web pages.

2. Frontend sends request

The browser sends the form data to the Flask backend.

3. Flask validates the input

Missing or invalid numeric values are blocked with clear error messages.

4. Preprocessing is applied

The system converts the data to the same format used during training, including scaling and feature ordering.

5. ML model makes prediction

The trained model evaluates the input and returns a class such as NORMAL, INTRUSION, SAFE, or SUSPICIOUS.

6. Result is saved

Prediction results are stored in SQLite and appear on the dashboard and in the history page.

Basic Concepts

  • Intrusion Detection System: A system that identifies unusual or malicious network behavior.
  • Machine Learning: A way for computers to learn patterns from data instead of hard-coding rules.
  • Classification: Predicting a category such as NORMAL or INTRUSION.
  • Spam detection: Detecting unwanted or suspicious messages.
  • Phishing: Fake messages designed to trick users into revealing credentials or money.
  • Precision: Of all the predicted attacks, how many were actually attacks?
  • Recall: Of all the real attacks, how many were correctly detected?
  • F1-score: A balanced score combining precision and recall.
